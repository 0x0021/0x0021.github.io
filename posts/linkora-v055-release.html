Linkora v0.5.5：记忆重构为「整合记忆」，已读后不再嘴瓢

AI Agent v0.5.5 记忆 体验

分身聊久了，记忆越攒越杂：一条条零散事实堆在一起，既冗余又让检索被噪声淹没。v0.5.5 把记忆从「一条条事实」升级为按「人 + 主题」聚合的整合记忆——后台周期性把零散事实合并成结构化摘要，召回直接返回摘要，更干净也更准。

记忆系统重构为「基于摘要的整合记忆」

  • 按人 + 主题聚合：个人记忆按对话对象聚合、公共记忆按主题桶（网络与访问 / 流程与审批 / 人员与组织 / 系统与账号 / 其他）聚合，后台调度器周期性把零散事实合并成结构化摘要，去重并保留关键事实。
  • 召回更干净：检索召回直接返回聚合后的摘要，召回质量更高、上下文更干净；记忆的私密度隔离（个人 / 公共）保持不变。
  • 存量自动迁移：已有的记忆已自动迁移并重算向量，无需手动操作。

已读之后再也不「嘴瓢」

修了「标记已读仍自动回复」的别扭体验：发送前强制拉取最新未读状态复核，并在标记已读后增加 3 秒「反悔窗口」——窗口内绝不发自动回复，避免刚点完已读就被分身再补一句。

今日摘要卡片不再串旧内容

「今日」摘要卡片的取材窗口收敛到当天，杜绝历史旧内容混入当日卡片，每天看到的就是当天该看的。

升级注意

无破坏性变更，无新增必填配置。记忆表结构向后兼容、自动迁移——你什么都不用改。

完整变更见 CHANGELOG；代码在 GitHub。
