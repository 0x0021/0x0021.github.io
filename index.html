Linkora v0.4.0 发布：认证迁移 pyjwt、出站 SSRF 默认拒绝、新增每日主动触达，并用 CI 护栏封死配置覆盖丢参数的事故路径。

给 Linkora 做了一套开源宣传图，嵌入 README、GitHub Pages 项目页和个人主页，深色/浅色双版本自动切换；顺手修了上下文组装里的发言人丢失 bug。

v0.4.1：公共记忆（scope=public）每轮对话自动召回并注入 system prompt，与 RAG 注入对称；移除 auth_middleware 中明文密码日志，CodeQL 告警清零。

v0.4.2：Web 侧栏「消息中心」新增独立「对话摘要」实时页（30s 轮询），与钉钉 17:30 主动触达推送完全同源；主动触达支持自定义时刻。

v0.4.3：对话摘要页从纯文本升级为结构化卡片（头像/平台标签/主题/关键词/建议待办），默认今日视图；修掉 get_store_dep 关闭全局单例导致 metrics 偶发 500 的隐性 bug；F5 刷新不再跳回首页。

修掉一个有意思的「时间窗口」bug：主动触达摘要推送原公式 max(今日0点, now - lookback_hours) 在 lookback_hours=24 时恒取今日 0 点，导致 17:30 推送只覆盖当日、漏掉昨日尾巴。改为 now - lookback_hours 滚动窗口，17:30 推送正确覆盖「昨日 17:30 → 今日 17:30」；同时复用 Web 同源的 list_recent_summaries(since=cutoff)，消除窗口错配与活跃会话 LIMIT 截断的双重隐患。

v0.4.4：摘要连续性补跑——启动检测停机时长，按自然日补生成遗漏的「当日 / 近七天」对话摘要，与正常周期同源同格式（均写回 conversation_summaries）；时区稳健、LLM 额度受 max_backfill_days 上限保护，异常不拖垮主链路。

v0.4.5：摘要视角修复——第一人称视角加固，summarize_conversation 新增显式 owner_name 参数并强制 prompt 约束「凡是主人的消息统一用『我』指代」，杜绝把主人当成第三方的混乱视角；四类生成链路共用同一函数，一次修复全生效。
